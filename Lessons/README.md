# SQL Data Engineering Projects

This repository contains SQL projects I have worked on to practice and strengthen my skills in SQL, data analysis, and data engineering.

## Project 1: Data Jobs Analysis

An exploratory analysis of Data Engineer job market trends using SQL. This project investigates demanded skills, high-paying opportunities, and the most optimal skills based on salary and demand.

## Key Learnings

- Writing SQL queries to analyze job market data.
- Using joins to combine information from multiple tables.
- Applying aggregation functions such as `COUNT()` and `MEDIAN()`.
- Filtering and sorting results using `WHERE`, `HAVING`, and `ORDER BY`.
- Comparing salary and demand to identify valuable skills.
